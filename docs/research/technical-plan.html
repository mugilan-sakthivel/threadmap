4. LLM: a small, fast model is enough

The LLM's job is narrow: read the latest transcript, return notes and diagram ops as JSON. It never draws or positions anything. That makes cheap models viable.

Your OpenCode key (Zen pay-as-you-go / Go $10/mo)Zen lists e.g. GPT-5.6 Luna $0.20 / $1.20, plus some free models (DeepSeek V4 Flash Free)Use for development now. Check OpenCode's terms before using it to power a public product. It's positioned for coding agents
Gemini 2.5 Flash-Lite / Flash~$0.10 / $0.40 (Flash-Lite)Strong production candidate: cheap, fast, good with Indian languages
GPT-5.6 Luna / GPT-5 mini~$0.20–0.25 / $1.20–2.00Reliable structured JSON

Cost per hour (live lane): about one call every 10s ≈ 360 calls/hr × ~3k input + ~300 output tokens ≈ 1.1M in / 0.1M out → ~$0.15/hr on Flash-Lite pricing, ~$0.35/hr on Luna pricing. Prompt caching of the fixed system prompt lowers it further.

Implementation: use the Vercel AI SDK (or any OpenAI-compatible client) so the model is just a config line. OpenCode Zen, Gemini, OpenAI, and Groq all plug in. Validate every response with a zod schema. Invalid JSON gets one retry, then is skipped (never crash the board).

5. Diagram engine: how “pyramid” becomes a pyramid

Key idea: a template library. The LLM detects the visual intent in speech and picks a template. Code draws the template. The AI never invents coordinates, so diagrams always look clean and never jump around.

Visual intents the LLM detects

TemplateExplicit cueImplicit cueDrawn as
Pyramid“pyramid”, “foundation… top”, “layers”Ranked levels building on each otherStacked boxes, widest at bottom (or a triangle with divider lines)
Quadrant / 2×2“four boxes”, “2 by 2”, “four corners”Two axes (“high effort vs low impact”)4 rectangles in a grid, optional axis labels
N methods / list“there are 4 methods / 3 ways”“first… second… third”N cards with numbered empty slots that fill in as they're explained
Steps / process“step 1, then, after that”Sequential actionsBoxes left → right with arrows
Funnel“funnel”, “top of funnel”Narrowing stagesShrinking boxes top → bottom
Cycle / loop“cycle”, “flywheel”, “it repeats”A → B → C → ANodes in a circle with arrows
Comparison“X vs Y”, “difference between”Pros and consTwo columns side by side
Timeline“in 2019… then in 2021”Dates, life storyHorizontal line with dated points
Mind map (default)—Topic with sub-pointsCentral node with branches (tree layout)

How it renders

  1. Sections. Each topic or question becomes a section (titled frame) stacked down the canvas. The current section is highlighted.
  2. Progressive fill. “There are 4 methods” immediately creates 4 dashed empty slots. Each slot turns solid when that method is explained. This feels magical on video.
  3. Template = pure function: (visual model) → Excalidraw element skeletons with fixed positions. Uses Excalidraw's convertToExcalidrawElements (rectangles, ellipses, text labels, bound arrows) and updateScene.
  4. Stable IDs. Element IDs derive from visualId + slotIndex, so updates modify elements in place, with no flicker.
  5. Re-shape on correction. “Actually five methods, not four” → resize_visual. “It's more like a cycle” → convert_visual keeps the labels and redraws the shape.
  6. Camera. Auto-follows the active section with smooth scroll. If the user pans manually, auto-follow pauses until they press “Follow live”.
  7. Fonts. Hand-drawn font for Latin text. Test Tamil/Devanagari early: if Excalidraw's hand-drawn font lacks those glyphs, set a Noto Sans fallback for non-Latin labels.

6. The LLM contract (ops schema)

// Input to the LLM each tick
{
  "recent_transcript": [ { "id": "s41", "speaker": "guest", "text": "..." } ],   // last ~2 min
  "board": [ { "id": "v2", "template": "quadrant", "title": "4 methods to get users",
               "slots": ["Cold DMs", "Content", null, null] } ],                  // compact state
  "map_language": "en"
}

// Output (validated with zod)
{
  "notes": [ { "type": "point" | "question" | "action" | "quote",
               "text": "Cold DMs: 50/day, must be personal", "source": ["s41"] } ],
  "ops": [
    { "op": "create_visual",  "id": "v3", "template": "pyramid", "title": "Growth framework", "slots": 3 },
    { "op": "fill_slot",      "visual": "v2", "index": 2, "label": "Partnerships", "detail": "co-host lives", "source": ["s44"] },
    { "op": "resize_visual",  "visual": "v2", "slots": 5 },
    { "op": "convert_visual", "visual": "v1", "template": "cycle" },
    { "op": "link",           "from": "v1", "to": "v3", "label": "leads to" },
    { "op": "set_active",     "visual": "v3" }
  ]
}

Prompt rules (core): only draw what was actually said · prefer filling existing visuals over creating new ones · create a visual only on a clear structure cue · labels ≤ 5 words in the map language · every op cites its source segment IDs · return empty ops when nothing new happened (most ticks).

8. Edge cases

CaseHandling
Speaker says “4 methods” but explains 3Leftover slot stays dashed. Shows up as a follow-up in notes (“4th method not covered”)
Speaker corrects themselvesresize_visual / convert_visual / update_slot ops, labels preserved
LLM returns invalid JSON or unknown IDszod validation → retry once → skip. Ops referencing unknown IDs are dropped
LLM call slower than tick rateSingle in-flight call. New finals queue and merge into the next call (no pile-up)
Hallucinated contentEvery op must cite source segments. Uncited ops are dropped
Silence or musicNo finals → no LLM calls. STT auto-pauses after N seconds of silence (cost)
Network dropBuffer audio locally, reconnect STT with backoff, mark a gap in the transcript
Long sessions (2h+)Older sections collapse to their titles. LLM context stays at ~2 min + compact board
Mixed scriptsTranscript shows the original. Map labels follow the chosen map language
Mic permission denied / no micClear error + “upload a recording” fallback (also used for demos)

9. Testing: replay mode is your secret weapon

  • Replay mode: feed a recorded audio file through the exact live pipeline at real speed. Same code path, so it's both your test harness and your demo-video generator.
  • Golden clips (10 to start): 2-minute clips containing a pyramid, 4 methods, steps, a comparison, and a correction. Each in English, Tanglish, and Hinglish.
  • Scores per clip: right template chosen? slots filled correctly? words→diagram latency? cost? Track in a simple table to compare STT and LLM options.
  • Unit tests: board reducer (ops → state) and each template (state → elements). Pure functions, fast tests.
