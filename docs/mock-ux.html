1. What we took from Flowjam

ElementFlowjam (measured)How we use it
Page#fdfdfc warm paper + subtle grain noiseApp background and the diagram canvas. It already looks like paper to draw on
GridDashed hairlines #e7e7e7, dots #d8d8d4Canvas dot grid + dashed dividers between diagram sections. A perfect fit for a drawing product
Display typeGelica (soft serif), 60px, −3px tracking, ink #160216Fraunces with SOFT axis (free, Google Fonts) for titles, speaker names, and notes
UI typeCraftwork GroteskHanken Grotesk (free) for small labels, timestamps, and numbers
Primary CTA#ff4de1 pill, text #570152, radius 60pxStart / End session, Export. One pink action per screen
Secondary CTADark gradient pill + deep layered shadowThe floating recording dock, “Upload recording”
Tag#ffa1ff pill with pink borderLanguage badge, “Live”, section labels
Option rowsGrey pill rows. Selected = black row with aurora glowSetup choices + the “open thread” highlight in Notes
StepsBlack numbered circles (1, 2, 3)New-session setup flow
LayoutSticky left rail (brand + CTAs) + content right, dashed column linesLanding page and setup screen
Radii / motionPills 60px, cards 18–32px, ease cubic-bezier(.2,.68,.26,1)Same scale. Diagram slots “rise in” with that ease

Gelica and Craftwork Grotesk are paid fonts, so we use free look-alikes. Since Flowjam is another company's brand, keep the design language (paper, dashed grid, soft serif, pills) but consider owning a distinct accent hue before launch so ThreadMap is recognizable on its own.
